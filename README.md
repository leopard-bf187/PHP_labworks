# 1. Инструкции по запуску проекта

1. Открыть терминал в папке проекта.

2. Установить зависимости: `composer require twig/twig`

3. Настроить подключение к базе данных в `config.php`.

4. Создать базу данных PostgreSQL: `CREATE DATABASE phplabdb;`

5. Выполнить миграции: `php migrate.php`

6. Запустить сервер `php -S localhost:8000 -t public`

7. Открыть в браузере: `http://localhost:8000/index.php?page=home`

# 3. Документация проекта

## 3.1 Содержание

Приложение состоит из следующих компонентов:
- публичная часть;
- система авторизации;
- пользовательский дневник;
- административная панель;
- система безопасности;
- база данных.


## 3.2 Функциональные возможности

### Общедоступные функции
- просмотр главной страницы;
- просмотр статистики;
- просмотр последних записей;
- регистрация;
- вход в систему.

### Пользовательские функции
- создание записи;
- редактирование записи;
- удаление записи;
- поиск записей;
- сортировка записей.

### Администратор
- просмотр всех записей;
- управление пользователями;
- создание администраторов;
- удаление пользователей;
- полный доступ к данным.


## 3.3 Сценарии взаимодействия

### Сценарий 1: Регистрация
1. Пользователь открывает страницу регистрации.
2. Заполняет форму.
3. Проходит CAPTCHA.
4. Данные валидируются.
5. Пользователь создается в базе данных.

### Сценарий 2: Вход
1. Пользователь вводит логин и пароль.
2. Проходит CAPTCHA.
3. Выполняется проверка через password_verify.
4. Создается сессия.

### Сценарий 3: Работа с дневником
1. Пользователь авторизуется.
2. Переходит в список записей.
3. Создает или редактирует запись.
4. Данные сохраняются в PostgreSQL.

### Сценарий 4: Администрирование
1. Администратор входит в систему.
2. Получает доступ к админ-панели.
3. Управляет пользователями и записями.


## 3.4 Структура базы данных

Таблица `users`
| Поле          | Тип     | Описание          |
| ------------- | ------- | ----------------- |
| id            | SERIAL  | ID пользователя   |
| username      | VARCHAR | Логин             |
| email         | VARCHAR | Email             |
| password_hash | VARCHAR | Хеш пароля        |
| role          | VARCHAR | Роль (user/admin) |


Таблица `moods`
| Поле  | Тип     | Описание |
| ----- | ------- | -------- |
| id    | SERIAL  | ID       |
| code  | VARCHAR | Код      |
| title | VARCHAR | Название |
| icon  | VARCHAR | Иконка   |


Таблица `entries`
| Поле         | Тип     | Описание     |
| ------------ | ------- | ------------ |
| id           | SERIAL  | ID записи    |
| user_id      | INT     | Пользователь |
| mood_id      | INT     | Настроение   |
| title        | VARCHAR | Заголовок    |
| mood_date    | DATE    | Дата         |
| energy_level | VARCHAR | Энергия      |
| note         | TEXT    | Текст        |
| tags         | TEXT[]  | Теги         |

# 4. Примеры использования

Пример создания записи
```php
$entryFormHandler->create($userId, $_POST);
```

Пример входа
```php
if (password_verify($password, $user['password_hash'])) 
    $_SESSION['user'] = $user;
```

Пример SQL-запроса
```sql
SELECT e.title, m.title
FROM entries e
JOIN moods m ON m.id = e.mood_id;
```
